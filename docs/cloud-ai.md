# Optional cloud text AI

October 7, 2026. Original implementation; no proprietary implementation or assets copied. The installed Vowen 0.5.9 settings and renderer contain provider labels OpenAI, Anthropic, Groq, Gemini, DeepSeek, OpenRouter, Azure, Cerebras, AWS Bedrock and Custom API, plus separate Claude Code and Codex CLI account entries. This factual inventory comes from privately retained `.private-analysis/extracted/dist-react/settings.js` and `main.js`, excluded from Git. SDK presence alone was not used as proof of a selectable provider. The free app's BYOK capability does not make external provider inference free.

`src/main/cloud-ai.js` exports `PROVIDERS`, `buildRequest(options)`, `normalize(provider,data)` and `chat(options)`. Root main/UI integration owns safeStorage, user selection and consent for context transmission. No provider credentials were accessed and no paid/cloud inference was requested. Fourteen real local HTTP fixture tests validate construction and response handling; these are not account-backed availability, quality, latency or billing evidence. Existing local Ollama implementation and tested qwen2.5:7b are unchanged.

Options: provider, explicit model, apiKey, messages (system/user/assistant string content) or prompt, optional system, images (`{mimeType,data}` base64), maxTokens, temperature, signal, timeoutMs. Azure also requires baseURL, deployment and apiVersion. Bedrock requires a region-specific runtime baseURL and an actual Bedrock bearer API key. Custom API requires a trusted baseURL including its desired API prefix. Every provider requires explicit model choice; the module does not fabricate a current model catalog.

Bedrock support uses its documented bearer API keys, not AWS access-key/secret SigV4. Existing IAM access keys, role credential discovery, short-term key generation and automatic key refresh are not implemented; the module never searches environment variables or local credential stores. Bedrock model IDs currently support simple IDs and regional inference profile IDs, not ARN paths. Provider model parameter support varies: models rejecting temperature should be called without it; max output token compatibility must be verified for the chosen deployment. No raw model API parameter passthrough exists.

Images are intentionally caller-supplied; this adapter does not capture screens, scrape foreground apps or load arbitrary files. Free context capture and attachments must be wired and verified independently by main/UI. PNG/JPEG/WebP/GIF are accepted, maximum 5 images, each 4 MiB decoded, 24 MiB total serialized request. Text files can be read elsewhere and placed in a user message; native PDF/document/file uploads and provider Files APIs are not implemented. Sensitive screen or file context must not be silently sent to a cloud provider. Prompt/context data remain untrusted content; a protocol adapter does not guarantee model resistance to instructions inside context.

Operational safeguards: HTTPS except explicitly enabled loopback fixtures; no URL credentials, redirects or arbitrary caller headers; CR/LF/NUL rejected in credentials; constrained native path identifiers and encoded Azure version; 100 message / 500,000 characters per-message caps; response cap 8 MiB; default 120-second timeout, maximum 15 minutes; AbortSignal cancellation. Error responses expose status, not provider bodies or keys. User-selected trusted baseURL is allowed; UI must never take that URL from an external prompt or document. Cancellation does not reverse upstream billing. Results return text, finishReason, usage and provider. Token-limited outputs retain finishReason; root should surface truncation. This implementation requests complete non-streaming replies and does not run tools, MCP, model-generated commands or web search.

Run `node --test tests/cloud-ai.test.js`. Tests cover all ten protocol selections, native system and assistant role mapping, image schema, headers, deployment paths, malformed paths/media/keys, HTTPS, empty output, error redaction and cancellation. No claim of live provider integration is made.
