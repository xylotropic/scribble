# AI utilities

Language models includes keyboard-triggered text utilities using six fixed presets: grammar correction, professional tone, polish, summary, bullet points and email. Each saved utility chooses selected text or clipboard text, a name, enabled state and optional captured keyboard shortcut. Bindings require a modifier and regular key and cannot conflict with another global or utility binding. Disabling a utility preserves its configuration but removes its binding from native interception. Edits and deletion update definitions/bindings atomically.

A utility uses the configured language model without recording. Empty selected text is an error; clipboard text is never substituted for a missing selection. The interface explains configured cloud-provider use and potential charges. Results are transient drafts for review, Copy, Dismiss or explicit Insert. Tab inserts only from the focused result; Escape dismisses. Cancellation suppresses late provider results. Starting another recording or processing job is rejected while a utility runs. Result IDs refer to exact backend-held text and cannot be used to replace it through the paste request.

Explicit insertion captures an opaque native target token before processing. The helper stores the original application and AX field, caps tokens at 32, expires them after ten minutes and consumes them on the first attempt. After explicit confirmation it activates the original application, verifies the same focused field and refuses missing, changed, expired or password targets before touching the clipboard. A failed attempt retains review text with Copy/Dismiss and removes Insert. Without an accessible external target, results are copy-only. OS paste fallback reports dispatch rather than verified insertion.

Store, UI, mocked main actions, native protocol and synthetic key events verify validation, conflict handling, single-fire utility keys, repeat/release suppression, cancellation, draft review and token refusal. Swift compilation passed. An actual local Ollama qwen2.5:7b grammar fixture is recorded in ai-utility-verification.json; it is a bounded output-quality check, not proof of every preset or provider. Physical global shortcuts, selected-text acquisition and native reinsertion remain unverified while macOS Accessibility authentication is pending. New utility text is not yet fully localized.
