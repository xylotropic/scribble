# Speech language metadata

Verified October 7, 2026 from primary model cards and the pinned runtime source. No new model downloads or inference were performed for this change. Tests verify metadata and selection normalization, not multilingual recognition quality.

- [NVIDIA Parakeet v3 card](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) specifies 25 European languages. `PARAKEET_MODELS.supportedLanguages` exposes those ISO codes; v2 exposes English only. The CoreML manifest fixes each conversion revision. [Pinned FluidAudio language enum](https://github.com/FluidInference/FluidAudio/blob/0b1f46289fe27d95b5e66ad8be46e64f5ee02ae7/Sources/FluidAudio/Shared/TokenLanguageFilter.swift) accepts all 25 codes. Its additional script-filter enums do not establish model coverage. Scribble's Swift Parakeet helper forwards a recognized enum as a decoding/filtering hint; automatic recognition remains the default, and automatic output language is currently `unknown` rather than a proven detected-language field.
- [NVIDIA Nemotron multilingual card](https://huggingface.co/nvidia/nemotron-3.5-asr-streaming-0.6b) separates usable locales from adaptation-only locales. `CATALOG_MODELS.supportedLanguages` exposes the 32 usable locales plus bare aliases that the pinned runtime can actually route. `adaptationLanguages` records the eight locales requiring fine-tuning; those are excluded from the regular picker.
- [Pinned CoreML metadata](https://huggingface.co/FluidInference/Nemotron-3.5-ASR-Streaming-Multilingual-0.6b-CoreML/blob/1a41b75758b0337ff67db7d5408280aaaf23074e/multilingual/2240ms/metadata.json) establishes prompt routing. The [conversion card](https://huggingface.co/FluidInference/Nemotron-3.5-ASR-Streaming-Multilingual-0.6b-CoreML/blob/1a41b75758b0337ff67db7d5408280aaaf23074e/README.md) advertises a larger prompt vocabulary; token availability alone does not establish usable ASR. In particular Vietnamese must use `vi-VN`, since `vi` has no prompt entry and the Swift helper does not map it. Scribble maps bare `zh`, `ja`, `en`, `es`, `fr`, `de`, `it`, `pt` to explicit supported locales; other exposed bare aliases exist in metadata. Regional selections preserve the exact locale.
- Japanese Parakeet, Chinese Parakeet and English Nemotron remain fixed-language models. Their supplied language parameter does not change recognition language. Whisper forwards `-l` to its native CLI; English-only models force `en`. No new Whisper language claim is introduced here.

`normalizeSpeechPreferences` resets incompatible local language selections to `auto` and continues resetting translation for engines that cannot translate. Unknown models and cloud settings remain untouched. Missing metadata preserves existing behavior. Root UI integration should show automatic plus the current model's supported list, with readable regional labels for Nemotron. Adaptation-only languages should not be presented as ready transcription choices.
