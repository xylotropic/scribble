# Optional cloud speech adapters

Original implementation, checked against official documentation on October 7, 2026. Scribble's source has no license charge for these adapters. Provider accounts, credits, keys and API usage are separate and can cost money. No provider key was read and no cloud inference request was made during implementation. Twenty-one tests use an actual local HTTP server with synthetic media and responses; this establishes protocol construction and error handling, not recognition accuracy, account access, production compatibility or provider service availability.

`src/main/cloud-speech.js` exports `CATALOG`, `transcribe(options)`, `normalize(provider,data)` and `endpoint(base,route,allowLoopback)`. Root main/UI integration must supply the key from safeStorage and explicitly select cloud speech. This module neither stores keys nor changes preferences. Results contain `text`, `language`, `duration`, `words`, `segments`, `provider`. Missing timing stays missing; malformed or reversed timing is discarded. Speaker IDs preserve provider labels and do not identify real people.

Languages are passed as provider-native codes; this module does not claim all providers accept the same codes. Unspecified language follows each endpoint's automatic detection/default. Actual recognition quality must be checked using an authorized account before claiming parity. Multipart model identifiers are data, not request paths; Gemini model identifiers are restricted to letters, numbers, dots, underscores and hyphens. Audio content can still influence generative Gemini transcription despite the defensive prompt.

Safety and operational limits: HTTPS required; explicitly enabled loopback HTTP exists for fixtures only. No redirect following. No credentials in URLs or bodies. CR/LF/NUL key/header input rejected. URLSearchParams encodes query values. A response body is capped at 8 MiB; default whole-operation timeout is 180 seconds, maximum 15 minutes, covering polling. AbortSignal cancels fetch and polling. HTTP errors do not echo provider bodies or keys. Base URL override is intended for a user-chosen trusted endpoint; UI must not silently populate it from external content. Remote API billing is not rolled back by local cancellation. AssemblyAI, Soniox and Speechmatics attempt DELETE only for IDs created by this invocation, after success, cancellation or error. Cleanup uses a separate bounded signal and returns per-resource `deleted` status via result.cleanup or onCleanup callback. A failed DELETE is recorded as false, never presented as deleted. Soniox can refuse deletion while processing; Speechmatics may report a locked job. AssemblyAI transcript deletion is attempted, but this adapter has no separate upload-delete endpoint. Provider retention/account deletion policies still apply. An aborted job-creation request may leave an unknown remote job ID that the client cannot clean up. Cancellation does not promise remote billing cancellation.

Accepted extensions: wav, mp3, m4a, mp4, flac, ogg, webm. Adapter caps are conservative application caps, not promises of provider maximums: 25 MiB for most multipart providers, 100 MiB for Deepgram/AssemblyAI, 12 MiB for Gemini inline media (base64 expands request size). File size is checked before and after reading. Full audio is held in memory for requests. Codec validity must be checked elsewhere. Long meeting chunking, live WebSocket transcription, translations, callback jobs, cleanup retries for locked resources, and provider-specific glossary controls remain outside this adapter's implemented scope.

Run `node --test tests/cloud-speech.test.js`. Fixtures cover every implemented provider route/auth/form or JSON schema, raw upload and polling, millisecond conversion, cancellation, missing/malformed timing, media size checks, header injection, HTTPS constraints and redirects, both new async protocols, punctuation assembly, own-resource cleanup, cancelled cleanup, failed deletion and malicious job IDs. No real cloud proof is claimed.
