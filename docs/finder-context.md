# Finder command context

Voice commands capture Accessibility context once before recording starts. Typed commands capture before their result UI. Only the frontmost `com.apple.finder` process supplies selected-file paths; text selection remains available for other applications. Refinements retain the original internal context. Renderer-provided `files` or `selectedFiles` are not trusted selection snapshots. Unavailable snapshots remain fixed empty context instead of rereading a later selection. Voice activation refuses a changed process owner; insertion targets must match the captured process and bundle.

The bridge reads AXSelectedChildren and AXURL within the focused window. It bounds window traversal to 512 elements, depth 12, queue 1024, and 32 selected paths. Selected items resolve their own URL first, then only decorative cell/text/image/group descendants to depth four with a shared 1024-node resolution budget. Descendant file rows are never treated as selected solely because an ancestor was selected. Limit overflow discards the partial path list. It accepts local file URLs only, preserves Accessibility enumeration order, and rechecks the frontmost process launch identity and focused window. It neither uses AppleScript/Automation nor changes the clipboard. Missing approval or an unsupported hierarchy yields unavailable context without requesting permission.

Recognized file commands use captured inputs and retain the existing destination picker. Empty/unavailable file context uses the existing input picker. Input count, format, regular-file/directory rules, symlinks and identity are checked before selecting a destination and again before calling the existing utility guard. Replacement, size or timestamp changes refuse execution. This narrows races but is not an atomic filesystem snapshot; files can still change while an underlying utility reads them. No file-operation success is reported when selection or execution fails.

Primary references: [Apple selected children](https://developer.apple.com/documentation/applicationservices/kaxselectedchildrenattribute), [Apple URL attribute](https://developer.apple.com/documentation/applicationservices/kaxurlattribute), and [Vowen Command Mode selected filenames](https://docs.vowen.ai/ai-features/command-mode). The local Apple SDK AXAttributeConstants.h specifies CFArray<AXUIElement> and CFURL values.

Synthetic fixtures verify URL rejection, selected ordering, renderer-path isolation, count/type guards, changed-input refusal, picker cancellation and refinement reuse. ARM and Intel compilation are checked separately. No actual Finder selection was queried; Finder view-specific AX shapes and selection-click order are unverified. Enumeration order is preserved, without claiming click chronology. Depth-limited or unexposed selections may require the picker. No native PDF/DOCX command-content upload is implied.
